⚡ Passo 3: Correção Rápida (Alternativa)

Se preferir uma correção mais direta, use este código no console do vendas.html:

// Correção rápida - cole no console do vendas.html async function correcaoRapida() { console.log('🔧 Aplicando correção rápida...'); const baseKey = 'romaneiosPct'; let tenant = null; try { const raw = localStorage.getItem('company_info'); if (raw) { const obj = JSON.parse(raw); tenant = obj && (obj.id || obj.companyId || obj.slug || obj.nome || obj.name); } } catch (e) {} const candidates = []; if (tenant) candidates.push(`companies/${tenant}/${baseKey}`); candidates.push(baseKey); let dados = null; for (const k of candidates) { const val = localStorage.getItem(k); if (val) { dados = val; break; } } if (!dados) { console.error('❌ Dados não encontrados'); return; } const romaneios = JSON.parse(dados); const selectRomaneio = document.getElementById('romaneioSelect'); const tipoRomaneio = document.getElementById('tipoRomaneio'); if (!selectRomaneio || !tipoRomaneio) { console.error('❌ Elementos não encontrados'); return; } // Definir tipo e limpar select tipoRomaneio.value = 'romaneiosPct'; selectRomaneio.innerHTML = ''; // Adicionar romaneios romaneios.forEach((romaneio, index) => { const option = document.createElement('option'); option.value = index; const data = romaneio.data ? new Date(romaneio.data).toLocaleDateString('pt-BR') : 'S/Data'; const cliente = romaneio.cliente?.nome || romaneio.clienteNome || 'Cliente não informado'; const volume = (romaneio.totalVolume || romaneio.volumeTotal || 0).toFixed(3).replace('.', ','); option.textContent = `${data} - ${cliente} - ${volume} m³`; selectRomaneio.appendChild(option); }); console.log(`✅ ${romaneios.length} romaneios PCT carregados!`); } correcaoRapida();

🔧 Solução Permanente

Para uma correção permanente, adicione esta linha no final do arquivo vendas.html, antes do fechamento da tag </body>:

<script src="corrigir_vendas_romaneios.js"></script> <script> // Aplicar correção automaticamente quando a página carregar window.addEventListener('load', function() { setTimeout(function() { if (typeof corrigirVendasRomaneios === 'function') { console.log('Aplicando correção automática...'); corrigirVendasRomaneios(); } }, 1000); }); </script>
⚠️ Importante:
• Mantenha um backup dos arquivos antes de fazer alterações permanentes
• Teste a solução em um ambiente de desenvolvimento primeiro
• Se algo der errado, atualize a página para voltar ao estado original
