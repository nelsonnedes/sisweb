Corrigir Regras do Firebase

Este assistente ajudará você a corrigir o erro PERMISSION_DENIED no Firebase.

1. Diagnóstico do Problema

O erro PERMISSION_DENIED ocorre quando as regras de segurança do Firebase não permitem a ação que você está tentando executar.

Erro detectado: Você não tem permissão para escrever no caminho /test_connection.

2. Solução: Atualizar as Regras de Segurança

Para corrigir este problema, você precisa atualizar as regras de segurança do seu banco de dados Firebase Realtime.

Regras Sugeridas

{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null",
    "test_connection": {
      ".read": true,
      ".write": true
    },
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid == $uid",
        ".write": "auth != null && auth.uid == $uid"
      }
    }
  }
}

Como aplicar estas regras:

  1. Acesse o Console do Firebase
  2. Selecione seu projeto sisweb-7ce82
  3. No menu lateral, clique em Realtime Database
  4. Vá para a aba Regras
  5. Cole as regras acima e clique em Publicar
Atenção! Estas regras são para fins de teste/desenvolvimento. Para um ambiente de produção, você deve configurar regras mais restritivas de acordo com a necessidade da sua aplicação.

3. Verificar Correção

Depois de atualizar as regras, teste novamente a conexão para verificar se o problema foi resolvido.

Problemas comuns e soluções

1. Autenticação

Se você estiver usando regras que requerem autenticação (auth != null), certifique-se de que o usuário está autenticado antes de tentar ler/escrever no banco.

2. Domínios autorizados

Se você estiver tendo problemas com autenticação, verifique se seu domínio (incluindo localhost) está na lista de domínios autorizados.

Vá para Authentication > Sign-in method > Domínios autorizados e adicione localhost à lista.

3. Caminhos específicos

As regras do Firebase são hierárquicas. Certifique-se de que as regras para o caminho específico que você está tentando acessar estão corretas.
